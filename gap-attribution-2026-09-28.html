TV price method

IMPORTANT lesson from tonight: omitting the timeframes param on a batch_run call after a prior call set timeframes:['D'] causes the LIVE CHART to stay on daily resolution and silently return stale daily data again — always pass timeframes explicitly on every call, never rely on an implicit 'current chart' default when a prior call changed it.

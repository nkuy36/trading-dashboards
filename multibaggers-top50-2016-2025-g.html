3 · Screener blueprint (Jan 1 observable only)

Sleeve A — Drawdown / cycle

  • Prior ADV ≥ $10M, price ≥ $5, ≥200 days
  • Dist to 2y high ≤ −45%
  • Prior-year return ≤ −15%
  • Energy / materials / beaten-down growth
  • Deploy after risk-off / commodity crash years

Sleeve B — Secular continuation

  • Same liquidity / price gates
  • Prior return +25% to +120%
  • Dist to 2y high −35% to −5% (running, not climax)
  • Active theme basket (AI infra, SaaS, power…)
  • Deploy when theme already live
